# 실습 03 · 회귀 숲 비교

**목표:** 분류와 회귀에서 입력은 같아도 정답·지표가 다름을 설명합니다.

**실제 정답 실행으로 확인한 출력**

```text
trees  MAE_ms  RMSE_ms
    20 611.158  708.812
   100 600.337  690.368
트리 수만 바꾸었습니다. MAE·RMSE는 작을수록 좋고 단위는 ms입니다.
```

**생성 파일:** `outputs/forest_regression.csv`

**완료·기록:**  

- 20개에서 100개로 늘렸을 때 두 오차가 모두 줄었나요?  
    두 오차 모두 줄었다.  
    MAE는 611.158 -> 600.337로 약 11ms,  
    RMSE는 708.812 -> 690.368로 약 18ms 줄었다.  
    RMSE는 크게 빗나간 요청에 더 민감하게 반응하므로, RMSE의 감소폭이 상대적으로 큰 것은 크게 빗나간 요청의 오차가 조금 작아졌음을 의미한다.
