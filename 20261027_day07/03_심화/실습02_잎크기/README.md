# 실습 02 · 잎 크기로 복잡도 조절

**목표:** 깊이와 최소 잎 크기를 한꺼번에 바꾸지 않고 하나씩 비교합니다.

**실제 정답 실행으로 확인한 출력**

```text
min_samples_leaf  leaves  train_F1  valid_F1
                1       4    0.7097    0.3333
                3       4    0.7097    0.3333
                5       4    0.7097    0.3333
```

**생성 파일:** `outputs/leaf_comparison.csv`

**완료·기록:** 

- 잎 크기를 늘리면 가능한 잎 수에 어떤 제약이 생기나요?  
    이 실습 코드에서 잎 하나에 필요한 학습 행을(=min_samples_leaf) leaf개로 설정했다.  
    잎의 개수는 (주어진 학습 행 수 / min_samples_leaf)를 넘을 수 없다.  
    따라서 잎의 크기를 늘리면 잎 수의 상한이 줄어들게 된다.
    이번 실습에서는 깊이가 3이므로 트리의 깊이에 따라서는 잎은 $2^{3}$인 8개까지 가능하다.  
    이번 실습에서는 leaf = 1, 3 ,5인 경우 모두 잎의 개수 상한은 8인데 실제 잎은 4개여서 상한에 걸리지 않고, 결과가 같게 나왔다. 

- valid 점수가 더 높다고 바로 최종 성능으로 발표해도 되나요?  
    그럴 수 없다.  
    valid에서 나온 점수는 검증 데이터 valid에 대한 설명력을 보여줄 뿐이다. 최종 성능은 설정을 고정한 뒤 한번도 쓰이지 않은 test data set을 통해 평가해야 한다.
