# 실습 04 · 순열 중요도

**목표:** 8개 MDI 값과 4개 순열 값을 같은 단위로 혼동하지 않습니다.

**실제 정답 실행으로 확인한 출력**

```text
MDI: 변환 후 8 열 / 순열: 원본 4 열
      feature  mean_F1_drop  repeat_std
  input_chars        0.0649      0.1227
allowed_tools        0.0478      0.1276
    task_type        0.1396      0.1136
     priority       -0.0619      0.1495
음수는 이 valid 표본에서 섞었을 때 점수가 높아졌다는 뜻입니다. 인과관계는 아닙니다.
```

주어진 실습에서 아래와 같은 순열중요도의 기대 결과치가 제시되어 있었으나, 위의 실제 수행 결과와 달라 파라미터 값을 변화시켜가며 확인한 결과,  
아래는 n_repeats = 10으로 설정했을 때의 결과로 확인되었다.  
```text
MDI: 변환 후 8 열 / 순열: 원본 4 열
      feature  mean_F1_drop  repeat_std
  input_chars        0.0678      0.1361
allowed_tools        0.0542      0.1185
    task_type        0.1737      0.0990
     priority       -0.0206      0.1801
음수는 이 valid 표본에서 섞었을 때 점수가 높아졌다는 뜻입니다. 인과관계는 아닙니다.
```

**생성 파일:** `outputs/mdi_importance.csv`, `outputs/permutation_importance.csv`

**완료·기록:** 

- 평균 감소량이 음수인 열은 어떻게 설명하나요?  
    순열 중요도의 평균 감소량은 한 열을 섞었을 때 F1 점수가 평균적으로 얼마나 떨어지는지를 나타낸다.  
    학습한 모델을 그대로 두고, valid를 이용해 F1을 재서 기준 점수로 삼는다.  
    특정 열의 값만 행끼리 무작위로 섞어 열과 정답 사이의 연결을 끊는다.  
    섞인 valid를 이용해 F1을 측정하고 기준 점수와의 감소량을 본다.  
    이를 주어진 횟수만큼 반복하여 평균 감소량과 표준편차를 얻는다.  
    평균 감소량이 음수라는 의미는 valid 표본에서 섞었을 때 F1 점수가 평균적으로 높아졌다는 의미이다. 즉, 이 모델과 valid 표본에서는 priority에 기대는 정도가 거의 없다. 그러나 priority 열에 대한 인과관계로 해석해서는 안된다.  
    valid 또한 20행으로 표본이 적고, 평균 감소량의 절대치가 -0.0619로 작으며 표준편차 또한 0.1495로 평균보다 크기 때문에, 표본이 작아 생긴 작은 흔들림으로 해석할 수 있다.  
    따라서 이 결과로 priority를 삭제할 근거는 되지 못한다.
- 이 결과로 특성을 골라버리면 valid를 선택에 사용한 것인가요?  
    그렇다.  
    위에서 설명한 순열 중요도의 의미상, valid로 중요도를 재고 특성을 고르게 되면 valid가 어떤 열을 쓸지 선택하는 근거로 사용된다.  
    Valid에 맞춰 열을 고르고 뒤에 같은 valid로 평가하면 점수는 좋은 쪽으로 편향되어 나오게 된다.  
    순열 중요도는 모델이 어떤 특성에 기대고 있는지를 관찰하는 목적으로만 사용해야 한다.
