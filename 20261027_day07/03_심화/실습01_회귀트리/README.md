# 실습 01 · 잎별 평균 확인

**목표:** 그룹별 평균과 회귀 예측을 연결합니다.

**실제 정답 실행으로 확인한 출력**

```text
분기 기준: 500.0
 leaf  count  mean_ms
    1      3    120.0
    2      3    720.0
250·850·1200 예측: [120.0, 720.0, 720.0]
```

**생성 파일:** `outputs/leaf_means.csv`

**완료·기록:**

- 왼쪽 평균 120, 오른쪽 평균 720을 손으로 계산해 보세요.
    왼쪽 평균: X가 500이하인 행은 왼쪽 잎으로 가므로, X = 100, 200, 300일 때 y=100, 120, 140.  
                  이 때 y의 평균은 120이다.
    오른쪽 평균: 500보다 큰 X = 700, 800, 900은 오른쪽 잎으로 가므로, y = 700, 720, 740.  
              이 때 y의 평균은 720이다.

- 1200을 예측하면 왜 720인가요?
    1200은 학습 범위(최대 900) 바깥이지만, 회귀 트리는 도착한 잎의 정답 평균만을 알려준다.
    1200은 분기 기준인 500보다 커 오른쪽 잎에 도착하므로, 오른쪽 잎에 도착하는 850과 1200 모두 720으로만 예측된다.
    선형 회귀의 경우 X가 커진다면 예측값도 커지므로 720보다 큰 값이 나온다.
    반면 회귀 의사결정 트리의 예측값은 항상 왼쪽 잎의 평균 120 또는 오른쪽 잎의 평균 720이다.
