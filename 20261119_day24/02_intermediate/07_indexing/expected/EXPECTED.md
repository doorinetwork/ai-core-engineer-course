# 예상 결과 · 실행 여부를 구분합니다

기본: prepared_only_not_db. --live-db에서 실제 저장·검색. 데이터 1~N행, 점수/시간은 실제 실행 후 확인.

실제 E5·DB 연동은 `--live-db`를 실행하고 사용자 PC의 결과를 직접 확인해야 합니다. 준비 예제를 실행한 결과를 실측값으로 기록하지 않습니다.

수치·해시·검색 순위는 실행 환경과 원문에 따라 달라질 수 있습니다. 특히 검색 점수와 실행시간을 고정된 정답으로 채우지 않습니다.

동봉된 `offline_reference_*.json`은 강사용 **DB 미접속 기본 실행**에서 생성된 기준 자료입니다. 실제 E5 Embedding·pgvector 검색 실측 기록으로 해석하지 마세요.
