# 입력의 출처와 범위
이 자료는 OpenCV로 직접 만든 정상 도형 이미지입니다. `square/circle/triangle` 3클래스이고 영상은 160×128, 10 FPS, 30프레임입니다.
`boxes_gt.csv`는 기하 정답이며 confidence가 없습니다. `boxes_fixture.csv`의 점수·박스는 **손으로 정한 원리 연습값**이고 YOLO 예측이 아닙니다.
`metrics_example.csv`도 **읽기 연습용 가상 학습 기록**입니다. 실제 성능으로 발표하지 마세요.
모든 박스는 연속 경계 `[x1,y1,x2,y2)`입니다. 면적에 +1을 쓰지 않습니다. 그림을 그릴 때만 표시 좌표를 반올림합니다.
각 split의 원본은 보존합니다. Test는 구조 감사 외에는 모델 학습·추론·임계값 선택에 쓰지 않습니다. 영상은 개발 데모로서 최종 test가 아닙니다.
빈 라벨 파일은 해당 그림에 대상 객체가 0개라는 명시적 정상 기록입니다. 빠진 라벨 파일과 구분합니다.
색상과 클래스가 연관된 쉬운 합성 문제이므로 자연 사진 성능이나 안전 관련 서비스의 정확도를 입증하지 않습니다.
`demo.pt`는 배포 시 들어 있지 않습니다. 강사의 준비 도구로 실제 Ultralytics 학습을 완료한 뒤 복사합니다. 학습되지 않은 모델을 자동 대체하지 않습니다.
